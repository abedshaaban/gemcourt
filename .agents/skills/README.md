# Blender skills

These project-local skills are vendored as regular files so they travel with a
Git checkout. They do not require the original machine's global skill install.

Included skills: `blender-modeling`, `blender-materials`, `blender-rendering`, and
`blender-export`, with their reference documents and evaluation examples.

Source: [RobLe3/cc-blender-skill](https://github.com/RobLe3/cc-blender-skill/tree/main/plugin/skills).
Copied on 2026-10-01. Each skill includes the upstream MIT license. Keep the
license when updating or redistributing these files.

The upstream examples use Blender MCP tools. For this project's asset generator,
run the Python script directly with Blender's background CLI; MCP is optional.
Skill installation does not install Blender itself.

See the project README for asset generation commands.
